# The Seasons (licensed)

Do **not** place DEMO files from `assets/03_Fonts/The_Seasons_DEMO_Not_For_Production/` here.

When a commercial web licence is available:

1. Add licensed **Regular** and **Italic** WOFF2 files (no VG unless designer-confirmed).
2. Register `@font-face` rules in `app/fonts.css`.
3. In `app/globals.css`, set `--serif: "The Seasons", Georgia, serif;`.
4. Remove the Cormorant Garamond Google Fonts link from `app/layout.tsx`.
